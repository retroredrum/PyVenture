# Assets du mini-jeu

Conventions :

- `rooms/<room_id>.png` : illustration par défaut d'une pièce, 320×180.
- `rooms/<room_id>_<variant>.png` : variante (ex. `cave_lit.png`).
- `objects/<object_id>.png` : icône d'objet, 32×32 ou 64×64.
- `endings/<ending_id>.png` : illustration de fin.

Les fichiers ne sont pas encore fournis. Le moteur générera un placeholder déterministe pour chaque asset manquant, afin de pouvoir jouer pendant le développement.

Format : PNG, pixel art, agrandissement entier au plus proche voisin.
